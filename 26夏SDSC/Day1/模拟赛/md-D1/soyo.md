## 题目描述
Nagasaki Soyo 现在急着去帮 Anon 打扫花园……

Soyo 面对了一棵具有 $n$ 个结点、$n-1$ 条边的无向连通树。输入的第 $i$ 条边的边权固定为 $i$。

你需要帮 Soyo 为每一条边指定单向通行方向。

Soyo 不想上坡，因此她认定一个定向方案不合法当且仅当：图中存在一条包含至少两条边的路径，路径上的边权沿着定向行走方向构成**上升序列**。

求满足 Soyo 要求的合法定向方案总数量，答案对 $998244353$ 取模。

## 输入格式
第一行一个整数 $n$。

接下来 $n-1$ 行，每行两个整数 $\(x,y\)$，代表一条无向边；输入次序为第 $1,2,\dots,n-1$ 条边，第 $i$ 条边权值为 $i$。

## 输出格式
输出一行一个整数，合法定向方案数模 $998244353$。

## 样例 1 输入
```
4
1 2
2 3
3 4
```
## 样例 1 输出
```
5
```

## 样例 2 输入
```
4
2 3
1 2
3 4
```
## 样例 2 输出
```
4
```

## 样例 3
见下发文件 `ex_soyo_3.in/ans`。

## 数据范围与提示
对于所有测试数据，保证：
- $1\le n \le 3\times 10^5$。

| 测试点编号 | $n$  | 特殊性质 |
| :--------: | :------: | -------- |
| $1\sim 2$  | $15$     | 无 |
| $3\sim 5$  | $3000$   | 无 |
| $6$        | $3\times 10^5$        | 第 $i$ 条边连接 $\(i,i+1\)$ |
| $7$        | $3\times 10^5$        | 第 $i$ 条边连接 $\(n,i\)$ |
| $8\sim 10$ | $3\times 10^5$ | 无 |
