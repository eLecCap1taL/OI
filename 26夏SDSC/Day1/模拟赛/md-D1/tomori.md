## 题目描述
Takamatsu Tomori 正偷偷在 Anon 的花园中捡石头……

现有 $n$ 颗石头在 Tomori 的桌子上排成一列，每颗大小均为 $1$ 单位，第 $i$ 颗的色深为 $a_i$。

Tomori 要做出最好的石头。

她会执行 $n-1$ 次合并操作：每次**等概率选取当前相邻的两颗石头**合并，然后丢弃一半。

具体地，$a_i$ 与 $a_{i+1}$ 合并后新色深为 $\frac{a_i+a_{i+1}}{2}$，总体积为 $2$，之后 Tomori 会抛弃一半，使得合并出的新石头大小仍为 $1$。

求最终仅剩一颗石头时，石头色深的数学期望，结果对模数 $998244353$ 取模

## 输入格式
第一行一个正整数 $n$。

接下来一行 $n$ 个整数，$a_i$ 代表第 $i$ 颗石头的色深。

## 输出格式
一行一个整数，$\(E(x)\)$ 在模 $998244353$ 意义下的值。

设最简分数 $\frac{a}{b}$，输出满足 $bx\equiv a\pmod{998244353}$ 且 $0\le x<998244353$ 的唯一整数 $x$。


## 样例 1 输入
```
3
11 45 14
```

## 样例 1 输出
```
374341653
```

对于所有测试数据，保证：

- $1\le n\le 10^6,\ 1\le a_i<998244353$

| 测试点 | $n$ 上限 |

| 1      | $\(n=1\)$    |
| 2,3,4  | $\(n=2\)$    |
| 5,6    | $\(n=3\)$    |
| 7,8,9  | $\le 10$ |
