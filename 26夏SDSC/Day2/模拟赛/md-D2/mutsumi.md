## 题目描述

人偶们的舞会结束了，Wakaba Mutsumi 终于摘下了面具。Mutsumi来到家中的地下室，准备把各个人格的爱拼接起来……

各个人格的爱形如一个长度为 $n$ 的整数数组 $a$。

每次操作，Mutsumi需要做以下两步：

1. 在当前的数组 $a$ 中，选择一个下标 $i$，满足 $1 \le i < len(a)$ 且 $a_i = i$。
2. 从数组中移除 $a_i$ 和 $a_{i+1}$，并将剩余的爱拼接起来组成新的数组。

请你帮 Mutsumi 求出最多可以执行上述操作多少次。

『Per aspera ad astra.』

『循此苦旅，终抵繁星』

## 输入格式

第一行包含一个整数 $n$，表示数组 $a$ 的长度。

第二行包含 $n$ 个整数 $a_1, a_2, \ldots, a_n$，表示数组 $a$ 的元素。

## 输出格式

输出一个整数，表示最多可以执行上述操作的次数。

## 样例 1 输入

```text
5
1 3 1 5 5
```

## 样例 1 输出

```text
2
```

## 样例 1 解释

一种最优操作序列为：

$$[1,3,1,5,5]\xrightarrow{i=1}[1,5,5]\xrightarrow{i=1}[5]$$

共执行 $2$ 次操作。

## 样例 2 输入

```text
8
1 2 3 8 8 8 8 8
```

## 样例 2 输出

```text
3
```

对于所有测试点，满足 $1 \le n \le 800$，$1 \le a_i \le n$。
| 测试点编号 | $n\le$ |
| :---: | :---: |
| $1\sim 4$ | $8$ |
| $5\sim 8$ | $50$ |
| $9\sim 14$ | $100$ |
| $15\sim 20$ | $800$ |
