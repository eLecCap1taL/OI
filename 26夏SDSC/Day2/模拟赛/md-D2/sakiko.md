## 题目描述

人偶们的舞会结束了，Togawa Sakiko 正躺在床上，在网上闲逛……

Sakiko 发现有文章提到等差数列。

Sakiko 知道求和是简单的，但她不禁好奇求其乘积会怎么样？

所以你需要帮 Sakiko 解决以下问题：给定一个等差数列，求它的各项乘积，你只需要输出其对 $1145141$ 取模的结果。

具体的，每组给定 $d,n,a$ 分别表示公差，长度，首项，你需要求出

$$
\prod_{i=0}^{n-1}(a+i\times d)\bmod 1145141
$$

注意，本题有多组测试数据。

『Ne vivam si abis.』

『君若离去，我不独生』

## 输入格式

第一行包含一个整数 $T$，表示测试数据组数。

对于每组测试数据，输入一行三个整数 $d,n,a$。

## 输出格式

输出共 $T$ 行，第 $i$ 行表示第 $i$ 组测试数据的结果。

## 样例 1 输入

```text
2
112342
298767
```

## 样例 1 输出

```text
809572
177562
```

## 样例 2 输入

```text
5
191917878741616
111111111110
112345
010
111451411
```

## 样例 2 输出

```text
0
0
224427
0
0
```

## 数据范围与提示

对于所有数据，满足 $0\le d,a\le 10^9$，$1\le n\le 10^9$，$1\le T\le 10^4$。

每个测试点的具体限制见下表：

| 测试点编号 | $n\le$ | 特殊性质 |
| :---: | :---: | :---: |
| $1\sim 3$ | $50$ | 无 |
| $4\sim 6$ | 无限制 | $d=1$ |
| $7\sim 10$ | 无限制 | 无 |
