## 题目描述

人偶们的舞会结束了，Yahata Umiri 回到了她的房间……身兼几十个乐队的贝斯手，Umiri 现在要在心中为它们评估信任值。

现在 Umiri 共有 $n$ 个乐队，排成一行，等待她评估信任值。初始所有乐队的信任值都是 $0$。

Umiri 会发放 $m$ 轮信任值。第 $i$ 次，她会考虑**前 $a_i$ 个**乐队，发放**总计 $b_i$ 的**信任值。

具体的，对于每一轮，Umiri 会**一点一点地**发放信任值，每一轮发放 $b_i$ 次。每次，她会把 $1$ 的信任值给最需要的乐队，即前 $a_i$ 个乐队中，当前拥有的信任值**最少**的乐队，如果前 $a_i$ 个中多个乐队的信任值数量相同，她会发给最靠前的乐队。

最终，Umiri 想让你帮忙求出每个乐队的信任值是多少。

『Facta fugis, facienda petis.』

『舍既成之本，逐未竟之业』

## 输入格式

第一行包含两个整数 $n,m$。

接下来输入共 $m$ 行，每行两个整数，分别表示 $a_i,b_i$。

## 输出格式

输出共 $n$ 行，第 $i$ 行表示第 $i$ 个乐队获得的信任值数量。

## 样例 1 输入

```text
9 3
5 11
8 4
4 7
```

## 样例 1 输出

```text
4
4
4
4
2
2
1
1
0
```

## 样例 1 解释

考虑每轮信任值发放之后的结果（第 $i$ 个数字是第 $i$ 个乐队目前拥有的信任值）：

```text
322220000
322222110
444422110
```

## 数据范围与提示

对于所有数据，满足 $1\le n,m\le 100000$，$1\le a_i\le n$，$1\le b_i\le 10^{12}$。

每个测试点的具体限制见下表：

| 测试点编号 | $n,m\le$ | 特殊性质 |
| :---: | :---: | :---: |
| $1\sim 4$ | $100$ | $b_i=1$ |
| $5\sim 9$ | $100$ | 无 |
| $10\sim 14$ | 无限制 | $b_i=1$ |
| $15\sim 20$ | 无限制 | 无 |
